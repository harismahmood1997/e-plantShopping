# e-plantShopping

Paradise Nursery is a React-based front-end shopping application for browsing houseplants, adding them to a cart, and managing quantities before checkout. Built with React, Redux Toolkit, and Vite, and deployed with GitHub Pages.

## Features
- Landing page with company info and a "Get Started" button
- Product listing page with plants grouped into categories
- Shopping cart with add, increase/decrease quantity, and delete functionality
- Live cart item count in the navbar

## Tech Stack
- React
- Redux Toolkit
- Vite
- GitHub Pages (deployment)
